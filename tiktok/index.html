Useful Small Systems · TikTok publisher

Owner-only tool. It connects the Useful Small Systems TikTok account to the publisher that runs on the owner's PC, so one finished reel a day can be posted. Nothing is stored on this page or sent anywhere except to TikTok's own sign-in.

1. Connect TikTok

You will be sent to TikTok to sign in and allow: profile info, upload video, post video.

2. Finish on the PC

TikTok sends you back to the callback page with a one-time code. On the PC run python -m calvin_automation.tiktok_publish exchange <code>, set the two env lines it prints, then python -m calvin_automation.tiktok_publish publish <post_id> --approval A-NNN.

3. Check the post

python -m calvin_automation.tiktok_publish status <publish_id> shows PUBLISH_COMPLETE, and the video appears on the account (private while the app is under review).
